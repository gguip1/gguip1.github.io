# Money World harnesses

This project can have multiple harnesses selected by verification purpose.

Possible future purposes include:

- `logic/`: amount conversion invariants
- `randomness/`: seeded repeatability, uniqueness, and distribution
- `browser/`: user flows
- `visual/`: result card layout
- `privacy/`: absence of unexpected network requests

Do not create a harness until its tool, command, artifacts, and pass conditions can be documented in its `HARNESS.md`.
