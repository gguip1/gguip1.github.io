# 그 돈으로

## Concept

사용자가 입력한 지출 금액을 그 돈으로 가능했던 뜻밖의 장면으로 환산한다.

## Product promise

사용자를 평가하거나 소비에 죄책감을 주지 않는다. 이미 한 선택 옆에 존재했던 재미있는 평행세계를 보여준다.

## Current foundation scope

- Provide an independently runnable static project shell.
- Link back to the portal.
- Make no external network request at runtime.

## Candidate behavior for the first product iteration

- Accept a KRW amount.
- Show three non-duplicate results with controlled variety.
- Allow rerolling without immediately repeating results.
- Support deterministic results with an injected seed for verification.
- Keep all conversion data in the project.

These behaviors are candidates until the first implementation task confirms them.
